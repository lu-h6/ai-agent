# AI Agent - 智能恋爱心理专家

基于 Spring AI + 通义千问大模型的智能对话系统,提供恋爱心理咨询、多轮对话记忆、增强检索(RAG)和 MCP 工具调用能力。

## 🚀 核心功能

### 1. 智能对话系统
- **多轮对话记忆**: 基于文件持久化的上下文记忆,支持跨会话历史回溯
- **流式输出**: SSE 实时打字机效果,提升用户体验
- **角色定位**: 恋爱心理专家,针对单身/恋爱/已婚三种状态提供建议

### 2. 增强检索 (RAG)
- **本地知识库**: 基于 Markdown 文档的向量检索
- **云知识库**: 集成阿里云百炼平台 RAG 服务
- **查询重写**: 自动优化用户提问,提升检索准确率

### 3. MCP 工具集成
- **图片搜索**: 调用 image-search-mcp-server 搜索相关图片
- **地图服务**: 集成高德地图 MCP,推荐约会地点
- **PDF 生成**: 自动生成恋爱报告、约会计划等文档

### 4. 超级智能体 (Manus)
- **自主规划**: 复杂任务分解与执行
- **工具编排**: 自动调用搜索、下载、文件操作等工具
- **流式反馈**: 实时展示思考过程和执行步骤

## 📦 技术栈

### 后端
- **框架**: Spring Boot 3.5.13 + JDK 21
- **AI 引擎**: 
  - Spring AI 1.0.0-M6/M7
  - Spring AI Alibaba 1.0.0-M6.1
  - 通义千问 DashScope SDK 2.19.1
- **向量数据库**: PostgreSQL + PGVector
- **序列化**: Kryo 5.6.2 (高性能二进制序列化)
- **文档处理**: jsoup 1.19.1, iText PDF 9.1.0
- **API 文档**: Knife4j 4.4.0 (OpenAPI 3)

### 前端
- **框架**: Vue 3.5.13 + Vite 6.2.0
- **HTTP 客户端**: Axios 1.8.4
- **路由**: Vue Router 4.5.1

### MCP 生态
- **MCP Client**: Spring AI MCP Client 1.0.0-M6
- **MCP Server**: image-search-mcp-server (独立部署)
